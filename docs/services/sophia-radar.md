# Sophia Radar Monitoring

Sophia Radar is a homelab monitoring dashboard tracking container status, system metrics, and network latency.

---

## Overview

Sophia Radar integrates container health checks, network ping latencies, and server telemetry into a single, unified status dashboard.

## Metrics Monitored

- **System Resources**: CPU load, RAM memory usage, and disk I/O
- **Container Health**: Docker container state checks via Docker API
- **Network Latency**: ICMP ping response times across Tailscale mesh nodes
- **Service Availability**: HTTP status codes for proxied web applications
